## 4. 口径说明
- 开发集（2009–2022），held-out 不参与调参。
- 真题解析 chunk 对所有路径都排除：解析逐字含题干，dev 题会自匹配。
- LLM-only 不给任何上下文，只靠参数化知识；它是判断「RAG 是否真的有用」的对照组。
- Agent 的考点统计只使用开发集年份，评测时 `get_kp_questions` 不返回答案、且排除当前题。
- Agent 在计算题按设计关闭 BM25（计算题 BM25 实测略负）；单轮使用统一 PROD 配置。
- 空回答单独统计，不算作正确，也不从分母里剔除；CI 用 2000 次 bootstrap。
- 图表 T3 的图是位图，当前无可用 VLM，因此 T3 上 Agent 与单轮 RAG 实质相同；**T1/T2 的增益不得记在检索链路的账上**。
